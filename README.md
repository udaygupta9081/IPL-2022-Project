# IPL 2022 Data Analysis and Visualization Project

## Overview
This project focuses on feature extraction, data analysis, and visualization of IPL 2022 data using Python. The objective is to extract meaningful insights and represent them visually using graphs and plots.

## Dataset
- IPL 2022 match and player data

## Key Work
- Loading and cleaning the dataset
- Feature extraction from IPL data
- Data analysis using Pandas and NumPy
- Visualization of data using Matplotlib and Seaborn
- Plotting graphs to identify trends and patterns

## Tech Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
